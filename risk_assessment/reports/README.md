# Risk Reporting Templates

This folder contains ready-to-use risk report templates, one per risk level,
generated by `engine/report_generator.py`. Each is a self-contained HTML file
(inline CSS, no external dependencies) that can be:
- opened directly in a browser,
- embedded in an iframe within the HealthTrack dashboard,
- emailed, or
- converted to PDF for download (e.g. via headless Chrome/LibreOffice).

## Templates

| File | Risk Level | Color | Example scenario |
|---|---|---|---|
| `templates/low_risk_template.html` | Low | Green (#2E7D32) | Stable, healthy adult vitals |
| `templates/moderate_risk_template.html` | Moderate | Yellow (#F9A825) | Diabetic patient, mild hypoglycemia |
| `templates/high_risk_template.html` | High | Orange (#EF6C00) | COPD patient, hypoxia + tachypnea |
| `templates/critical_risk_template.html` | Critical | Red (#C62828) | Sepsis-pattern vitals cluster |

Each template shows, in order:
1. **Header** — patient name/ID, generation timestamp, risk-level badge
2. **Risk Score** — total points (0-21), per-metric breakdown table, and the
   predictive model's estimated 72h adverse-event probability if available
3. **Risk Trend** — direction (worsening/stable/improving), slope, and how
   many historical readings the trend is based on
4. **Contributing Risk Factors** — every metric that scored above 0, any
   detected compound clinical patterns (e.g. "possible sepsis pattern"),
   and any personal-baseline deviations
5. **Recommendations** — always preceded by a visible
   "SYSTEM-GENERATED SUGGESTION" disclaimer; never phrased as a diagnosis

## Generating a new report

```python
from engine.report_generator import build_patient_report, render_html_report

report = build_patient_report(
    patient_id="PT-12345",
    patient_name="Jane Doe",
    reading={...},                # current vitals dict
    history_scores=[1, 2, 3],     # prior total_score values, chronological
    history_timestamps=[0, 6, 12],# matching hours-elapsed
    model_probability=0.34,       # optional, from predictive_model.predict_patient_risk()
)
html = render_html_report(report)   # for display / download
# report itself is a plain dict -- json.dumps(report) for API responses
```

## Customizing

The HTML template lives in `engine/report_generator.py` as `HTML_TEMPLATE`
(a Python `string.Template`). Colors are driven by `risk_classification.py`'s
`color_hex` values, so re-theming the palette only requires editing one file.
Sample JSON payloads for three scenarios are included alongside the HTML
examples in this folder (`sample_report_*.json`) as a reference for
front-end/API consumers.
